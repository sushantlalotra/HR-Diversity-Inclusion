# 🤝 HR Diversity & Inclusion - Power BI Project

## 📊 Project Overview
This project analyzes workforce diversity and inclusion metrics to help organizations assess and improve their HR policies. Using Power BI, the dashboard provides insights into employee demographics, diversity ratios, gender representation, and inclusion trends.

---

## 🎯 Key Objectives
1. Measure workforce diversity based on gender, ethnicity, age, and other demographics.
2. Identify representation gaps and inclusion opportunities.
3. Analyze employee sentiment and retention trends.
4. Provide actionable insights for HR decision-making.

---

## 🚀 Features
- **Dashboard Highlights**:
  - **Diversity Metrics**: Workforce composition by gender, ethnicity, and age groups.
  - **Inclusion Index**: Employee engagement and retention trends.
  - **Salary & Role Distribution**: Pay equity analysis and career growth opportunities.
  - **Hiring & Promotion Trends**: Diversity representation in hiring and leadership roles.
- **Interactive Reports**:
  - Filters for department, location, and employee tenure.
  - Drill-through analysis for detailed insights.

---

## 🛠 Tools Used
- **Power BI**: For interactive dashboards and diversity analysis.
- **Excel/MySQL**: Data sources for storing and preprocessing HR data.
- **DAX (Data Analysis Expressions)**: For calculating diversity KPIs.
